# 独立站启动清单

这个仓库已经被整理成一个适合继续品牌化和独立部署的骨架。你下一步只需要先做几项关键决策，就可以继续往上线方向推进。

## 1. 先定这 5 个名字和配置

1. 品牌名
   建议 2 到 3 个英文音节，域名更好买，也方便做 Logo。
2. 主域名
   推荐直接买 `.com`，如果没有可选 `.io`、`.app`、`.ai`。
3. 站点简介
   一句话说明你到底是做“视频下载器”还是“视频内容助手”。
4. 支付定位
   先决定卖“会员”还是“按量额度包”。
5. AI 供应商
   现在已经可以在 OpenAI 和 DeepSeek 之间切换，推荐默认先用 OpenAI。

## 2. 改名字主要改这几处

- `frontend/.env`
- `frontend/.env.example`
- `backend/.env`
- `backend/.env.example`
- `frontend/public/sitemap.xml`

前端页面里的品牌、价格、域名、SEO 标题已经尽量收口到了 `frontend/src/config/site.js` 和 `frontend/.env`。

## 3. 服务器上线前要补的内容

1. 购买域名并解析到服务器
2. 买一台 Linux 服务器
3. 部署前端静态文件
4. 部署 FastAPI 后端
5. 用 Nginx 做反向代理和 HTTPS
6. 配置 Stripe 回调地址
7. 配置 `.env` 里的生产环境域名和 CORS

## 4. 当前更适合你的服务器规格

- 早期验证版：2 vCPU / 2 GB 内存
- 有 AI 总结和一定并发：2 vCPU / 4 GB 内存
- 如果下载量明显上来：4 vCPU / 8 GB 内存，并把大文件下载流量和 AI 请求拆开

## 5. 建议你尽快决定的方向

- 如果你想主打工具站流量：品牌名要偏通用、偏搜索词友好
- 如果你想做作品集项目：品牌名可以更产品化、更有记忆点
- 如果你想真的收款：建议把“下载”放成入口，把“AI 总结”和“字幕整理”做成付费能力
